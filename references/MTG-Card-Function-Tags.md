# MTG Card Function Tags

Use these tags to categorize the purpose of each card in a deck. A single card may carry multiple tags — apply every tag that reflects a genuine role the card plays.

## Quick Reference — Top-Level Categories

| Tag | Use for |
|-----|---------|
| `Card Advantage` | Draw, selection, impulse draw, looting, graveyard value |
| `Removal` | Targeted removal, board wipes, bounce, exile, fight |
| `Countermagic` | Hard counters, soft counters, stax, protection, redirect |
| `Mana` | Ramp, rocks, dorks, cost reduction, rituals, treasure |
| `Recursion` | Graveyard recursion, reanimation, flashback, self-mill |
| `Tutors` | Library search of any kind |
| `Win Conditions` | Finishers, combo pieces, alternative wins |
| `Creatures` | Evasion, utility, beaters, blockers, tokens, anthems |
| `Synergy` | Tribal payoffs, aristocrats, ETB/LTB payoffs, sacrifice |
| `Enchantments` | Auras, equipment, sagas, enchantress, artifact payoffs, voltron |
| `Resource Denial` | Land destruction, hand disruption, lockpieces, taxation, pillow fort |
| `Utility` | Haste enablers, copy effects, flicker, political, catch-all, hate bears |

## Card Advantage

| Tag | Description | Examples |
|-----|-------------|---------|
| `Card Draw` | Directly draws one or more cards | Rhystic Study, Phyrexian Arena |
| `Card Selection` | Filters without drawing (Scry, Surveil, etc.) | Brainstorm, Ponder |
| `Impulse Draw` | Exile-then-play effects | Reckless Impulse, Light Up the Stage |
| `Looting` | Draw then discard | Faithless Looting |
| `Rummaging` | Discard then draw | Seasoned Pyromancer |
| `Graveyard Value` | Generates advantage from the graveyard | Eternal Witness, Flashback spells |

## Removal

| Tag | Description | Examples |
|-----|-------------|---------|
| `Targeted Removal` | Destroys or exiles a single permanent | Swords to Plowshares, Path to Exile |
| `Spot Removal` | Instant-speed single-target kill | Terminate, Fatal Push |
| `Board Wipe` | Destroys or exiles multiple permanents at once | Wrath of God, Damnation |
| `Partial Wipe` | Conditional or selective mass removal | Meathook Massacre, Toxic Deluge |
| `Bounce` | Returns permanents to hand | Brazen Borrower, Chain of Vapor |
| `Tuck` | Puts permanents on top of or into the library | Hinder, Oblation |
| `Exile` | Non-destroy removal (harder to interact with) | Anguished Unmaking, Generous Gift |
| `Fight` | Forces creatures to deal damage to each other | Prey Upon, Inscription of Abundance |
| `Sacrifice Outlet` | Forces or enables sacrificing permanents | Altar of Dementia, Viscera Seer |

| Tag | Description | Examples |

| `Counterspell` | Counters spells on the stack | Counterspell, Fierce Guardianship |
| `Soft Counter` | Conditional counterspell (tax, unless, etc.) | Mana Leak, Mystic Snake |
| `Stax` | Restricts what opponents can do | Rhystic Study, Sphere of Resistance |
| `Protection` | Grants hexproof, shroud, indestructible, or phasing | Teferi's Protection, Swiftfoot Boots |
| `Redirect` | Changes targets of spells or abilities | Deflecting Swat, Chromatic Orrery |

## Recursion

| Tag | Description | Examples |
|-----|-------------|---------|
| `Recursion` | Returns cards from graveyard to hand or battlefield | Eternal Witness, Regrowth |
| `Reanimation` | Returns creatures specifically from graveyard to play | Reanimate, Animate Dead |
| `Flashback / Escape / Disturb` | Built-in graveyard replay mechanics | Past in Flames, Unburial Rites |
| `Graveyard Hate` | Exiles or disrupts opponents' graveyards | Rest in Peace, Tormod's Crypt |
| `Self-Mill` | Intentionally fills your own graveyard | Stitcher's Supplier, Altar of Dementia |

## Tutors

| Tag | Description | Examples |

| `Creature Tutor` | Searches specifically for creatures | Fierce Empath, Chord of Calling |

## Win Conditions

| Tag | Description | Examples |
|-----|-------------|---------|
| `Win Condition` | Primary way to close out the game | Thassa's Oracle, Aetherflux Reservoir |

| `Enabler` | Makes combo pieces or synergies function | Goblin Welder, Emry, Lurker of the Loch |
| `Finisher` | A late-game threat that ends games quickly | Blightsteel Colossus, Craterhoof Behemoth |
| `Beatdown` | Wins through sustained combat damage | Tarmogoyf, Questing Beast |

|-----|-------------|---------|

## Utility

| Tag | Description | Examples |
|-----|-------------|---------|
| `Haste Enabler` | Grants haste to creatures | Swiftfoot Boots, Concordant Crossroads |
| `Copy Effect` | Copies spells or permanents | Strionic Resonator, Delina, Wild Mage |
| `Flicker / Blink` | Exiles and returns a permanent, resetting ETBs | Conjurer's Closet, Ephemerate |
| `Draw-Go` | Designed for instant-speed play in control | Cryptic Command, Mystic Confluence |
| `Political` | Creates deals or affects group dynamics (Commander) | Zedruu the Greathearted, Tempt with Reflections |
| `Catch-All` | Flexible utility applicable to many situations | Generous Gift, Chaos Warp |
| `Hate Bear` | Low-cost creature that disrupts opponent strategies | Thalia, Guardian of Thraben; Eidolon of the Great Revel |
| `Silver Bullet` | Narrow card included specifically for one matchup | Leyline of the Void, Damping Sphere |
| `Sideboard` | Card designated for the sideboard (60-card formats) | Rest in Peace, Mystical Dispute |

## Tagging Guidelines

- **Apply all relevant tags.** A card like Reclamation Sage is both `Targeted Removal` and `Utility Creature`. Apply every tag that reflects a genuine role.
- **Format context matters.** Tags like `Sideboard`, `Silver Bullet`, and `Hate Bear` are most relevant in 60-card formats. `Political` is almost exclusively a Commander concern.
- **Two tag types — Global and Deck.**
  - **Global Tags (`#!`)** cover the card's universal mechanical function — roles that would apply to this card in any deck. Use these for broad, format-agnostic categories like `Ramp`, `Removal`, or `Card Draw`.
  - **Deck Tags (`#`)** cover the card's strategic role in *this specific deck*. Use these when a card's value is tied to the deck's particular theme, commander mechanic, or combo — roles that wouldn't apply to the card in most other contexts.
  - A card can carry both types. Example: `Altar of Dementia` in a Meren deck → `#!Sacrifice Outlet #!Self-Mill #Win Conditions` (global roles any deck would recognize, plus a deck-specific combo role).
- **Revisit tags when the deck changes.** A card's role can shift as the deck evolves — a `Tutor` target may become a `Win Condition` in a different build.
