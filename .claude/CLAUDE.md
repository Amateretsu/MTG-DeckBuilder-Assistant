# MTG Deckbuilder — Instructions

Always verify every card via Scryfall before including it in any output. Never use assumed or memorized set codes or collector numbers.

## Output Convention (all skills)
Save files to `/mnt/user-data/outputs/`. Call `present_files` once after all files for a task are saved.

## Deliverables
Before producing any output, read the relevant skill:

| Task | Skill |
|------|-------|
| Export decklist + write primer | `mtg-export` |
| Quick visual dashboard (charts only) | `mtg-visualization` |
| Deep analysis + visualization (consistency, strengths/weaknesses, role balance) | `mtg-deck-analysis` |
| Budget swap guide | `mtg-budget-swaps` |

references/MTG-Card-Function-Tags.md is the reference for all tag names and card categorization.
